# BustikDupe — Fabric 1.21.4

Сборка без Linux/Termux: GitHub Actions.

1. Создай пустой репозиторий на GitHub.
2. Загрузи содержимое этого ZIP в репозиторий.
3. Открой вкладку Actions.
4. Выбери `Build Fabric mod` и запусти workflow.
5. После сборки открой результат workflow → Artifacts → `BustikDupe-jar`.
6. Скачай ZIP из Artifacts и достань `.jar` из него.

Workflow находится в `.github/workflows/build.yml`.
